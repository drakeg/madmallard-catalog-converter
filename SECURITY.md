# Security
Testing prototype only. Use authorized, non-sensitive documents until security and extraction validation are complete. Files are processed in browser memory; no content is sent to a server. Dependencies and worker are bundled locally. Static hosting receives routine requests. No localStorage, analytics, remote APIs, eval-based PDF parsing or automatic inventory changes. Size/page/row limits reduce accidental resource exhaustion, but untrusted PDFs remain a parsing risk. Dependency audits do not prove absence of vulnerabilities. Review all exports; formula-looking cells are escaped. Currency and prices require manual checks. Report vulnerabilities privately to the repository owner; never attach confidential documents to public issues.
